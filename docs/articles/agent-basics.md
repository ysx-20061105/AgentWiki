## 什么是 AI Agent？

AI Agent（人工智能代理）是一种能够**自主感知环境、做出决策并执行行动**的智能系统。与传统的聊天机器人不同，Agent 具备以下核心能力：

- **自主性**：能够在无人干预的情况下完成复杂任务
- **工具使用**：可以调用外部工具和 API
- **推理能力**：通过 LLM 进行逻辑推理和规划
- **记忆能力**：维护短期和长期记忆

## Agent 的核心组成

一个典型的 AI Agent 系统由以下部分组成：

```
┌─────────────┐
│   用户输入    │
└──────┬──────┘
       ▼
┌─────────────┐
│  LLM 大脑    │  ← 推理与决策
└──────┬──────┘
       ▼
┌─────────────┐
│  工具调用     │  ← 搜索、代码执行、API 调用等
└──────┬──────┘
       ▼
┌─────────────┐
│  记忆系统     │  ← 短期记忆 + 长期记忆
└──────┬──────┘
       ▼
┌─────────────┐
│   输出结果    │
└─────────────┘
```

### 1. LLM 大脑

LLM（大语言模型）是 Agent 的核心推理引擎。它负责：

- 理解用户意图
- 分析任务并制定计划
- 决定下一步行动
- 整合信息生成最终回复

### 2. 工具调用（Tool Use）

Agent 可以通过 **Function Calling** 机制调用外部工具：

```python
# 示例：定义一个搜索工具
tools = [
    {
        "name": "web_search",
        "description": "搜索互联网获取最新信息",
        "parameters": {
            "type": "object",
            "properties": {
                "query": {
                    "type": "string",
                    "description": "搜索关键词"
                }
            },
            "required": ["query"]
        }
    }
]
```

### 3. 记忆系统

| 类型 | 说明 | 示例 |
|------|------|------|
| 短期记忆 | 当前对话上下文 | 最近的对话消息 |
| 长期记忆 | 持久化存储的知识 | 向量数据库、文件系统 |
| 工作记忆 | 任务执行中的临时状态 | 当前任务的中间结果 |

## Agent 的工作循环

Agent 通常遵循 **感知-思考-行动** 的循环：

1. **感知（Perceive）**：接收用户输入和环境信息
2. **思考（Think）**：使用 LLM 进行推理和规划
3. **行动（Act）**：调用工具或生成回复
4. **观察（Observe）**：获取行动结果
5. **重复**：基于观察结果继续推理，直到任务完成

> 这个循环也被称为 **ReAct（Reasoning + Acting）** 模式，是目前最主流的 Agent 架构之一。

## 常见的 Agent 架构

### ReAct 架构

ReAct 将推理和行动交织进行，每一步都先推理再行动：

```
Thought: 我需要搜索最新的 Agent 论文
Action: web_search("AI Agent 最新论文 2026")
Observation: 找到了以下相关论文...
Thought: 根据搜索结果，我来总结关键发现...
Action: 给出最终回答
```

### Plan-and-Execute 架构

先制定完整计划，再逐步执行：

```
Plan:
  1. 收集相关资料
  2. 分析关键技术
  3. 撰写总结报告

Execute:
  → Step 1: 调用搜索工具收集资料
  → Step 2: 分析提取的关键信息
  → Step 3: 生成结构化报告
```
